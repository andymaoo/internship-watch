## Moody's location omission

`moodys-campus` reproducibly failed on one of 47 current official directory
rows. Requisition `101601004096`, “Ratings and Research Support Working Student
- Financial Institutions Group,” retained an exact employer detail page,
description, schema identifier `14721`, employer date, employment type and a
matching SuccessFactors application. Its JobPosting JSON-LD alone omitted
`jobLocation`. The same exact job detail rendered one title-matched
`job-description__job-location-info` value, `Hong Kong`.

The adapter now uses that visible employer-detail location only when structured
addresses are absent. It requires the expected heading/location classes, an
exact normalized title match and exactly one nonempty location. Missing or
ambiguous evidence still raises a source error. Structured locations follow the
unchanged path. The fallback records `location_kind` as
`employer_displayed_detail` and leaves structured country unknown. The affected
foreign working-student role remains outside the user's US filter.

The focused regression proves the exact fallback and proves that a page missing
both forms of location still fails. The repaired live adapter returned all 47
rows and used the fallback exactly once.

## HubSpot source retirement

The configured `hubspotjobs` Greenhouse board now returns a stable HTTP 404
while other Greenhouse boards work. HubSpot's official careers directory is a
current JavaScript shell, but its backing public frontend GraphQL endpoint is
unavailable under the site's robots policy. No access control was bypassed and
no complete permitted structured replacement was established.

The dead direct source is disabled with an explicit reason. HubSpot remains in
the watchlist through the configured Simplify public feed and is labeled
`public_feed_incomplete`; that feed cannot establish complete or immediate
HubSpot coverage. This changes the example and production-intended source count
from 213 to 212 enabled sources and the direct-company count from 188 to 187.
It does not remove prior HubSpot jobs, identities, observations or deliveries.
